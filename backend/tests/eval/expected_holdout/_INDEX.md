# Holdout set — boletas reales de internet (no vistas por el pipeline)

Set de generalidad **separado** de `expected/` (no comparte imágenes ni fuentes). Imágenes en `../receipts_holdout/`, ground truth en este directorio, mismo formato que `expected/*.json` + campos extra `source_url`, `license`, `notes`, `tags` (y `merchant_contains_alt` en un caso).

**32 imágenes.** Todas verificadas a mano: Σ line_total = subtotal impreso (o TOTAL cuando no hay subtotal) en todas salvo `goteron_ayna_handwritten` (items_lenient: importes seguros, asignación a platos incierta) y `la_dieta_de_nos_vinadelmar` (sin ítems).

Convenciones usadas:
- `amount` = total final cobrado. Propina/servicio sugerido no se suma salvo que el TOTAL impreso lo incluya (Petra, Willi's lo incluyen como *service charge*).
- `total_neto`/`iva_amount`: se llenan cuando el ticket desglosa impuesto. Para impuesto sumado encima (EE.UU., India, Jordania, Marbella) neto = subtotal de ítems; para IVA incluido (España, Austria, Polonia, Italia) neto = base impresa (en Polonia e Italia el neto es calculado = total − IVA impreso, ver notes).
- Ítems pesados: `quantity: 1` y `line_total` = importe de la línea (no el peso ni el $/kg).
- `item_count_max` se usa cuando fusionar líneas idénticas o listar un descuento como línea es igualmente válido.
